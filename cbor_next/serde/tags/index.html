Serde types for registered tags Serde types for tags registered by RFC 8949 and RFC 8742.

Each is a TaggedWith of its number, so reading checks the number. Embedded and EmbeddedSequence also encode and decode their bytes.

Bignums need no type (i128/u128). For tags 4 and 5 use TaggedWith<4, (i64, i128)>; Tagged keeps any tag.
