Module for the tags registered by RFC 8949 and RFC 8742 The tags registered by RFC 8949 and RFC 8742 which carry a value through serde.

Each one is written and read as a TaggedWith of the number in crate::tags around the content type the registry requires, so the tag number is checked when reading. Embedded and EmbeddedSequence go further and encode or decode the CBOR their byte string holds.

Bignums, tags 2 and 3, need no type: an i128 or u128 outside the range of a major type 0 or 1 item is written as one, and one is read as such. Tags 21 to 23 only advise a converter to JSON on how to write a byte string, and tags 4 and 5 are a pair of an exponent and a mantissa, which TaggedWith<4, (i64, i128)> carries; a Tagged keeps any of them as it is.
