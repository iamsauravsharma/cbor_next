Module for encoding data items Turning data items into CBOR bytes.

DataItem::encode uses the default settings of Encoder, which keep every item exactly as it is held. An Encoder built by hand can instead normalize what it writes, for example to emit the deterministic form of a value without first rewriting the value itself.
